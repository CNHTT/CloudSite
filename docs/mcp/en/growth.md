# Site growth: inquiries, chat, subscriptions, analytics and SEO

The injected `enhance.js` writes inquiries, live chat, subscriptions, visitor accounts, conversion events and page analytics back to Bweb. These tools let the AI read and act on that data. **31 tools**.

Every tool runs inside the token's account and site scope. Read-only tokens can only call read tools.

## Overview and analytics

| Tool | R/W | What it does |
| --- | --- | --- |
| `enhance_overview` | Read | Per-site summary of leads, conversations, conversions, events and visitors |
| `enhance_analytics_summary` | Read | Single-site analytics: daily views / forms / leads / conversions, revenue, sources, funnel and top pages; filter by `days` and `language` |

## Forms and leads

| Tool | R/W | What it does |
| --- | --- | --- |
| `enhance_forms_list` | Read | Form list with field definitions (key / label / kind / required / options) |
| `enhance_form_get` | Read | One form and its fields |
| `enhance_form_create` | Write | Create a form with built-in or custom fields |
| `enhance_form_update` | Write | Update a form; omitted fields keep their values |
| `enhance_form_delete` | Write | Delete a form (collected leads are kept) |
| `enhance_leads_list` | Read | List leads, filter by `site` / `status` / `limit`, up to 1000 |
| `enhance_lead_update` | Write | Update status, note, assignee and next follow-up time |
| `enhance_lead_assignees` | Read | Team members who can be assigned leads |

- Lead statuses: `new`, `contacted`, `qualified`, `closed`, `spam`.
- `enhance_lead_update` supports `assignee_email` (empty string clears it) and `next_follow_up_at` (ISO 8601; empty string clears it). Setting a follow-up sends a reminder email to the assignee, or to the account owner when unassigned.
- MCP returns full contact details for leads, including email, phone and values in the `custom` field. Treat the token as business data.

## SEO / GEO audit

| Tool | R/W | What it does |
| --- | --- | --- |
| `enhance_seo_audit` | Read | Check `index.html`, `robots.txt`, `sitemap.xml`, `llms.txt` / `llms-full.txt`; return a score, per-item evidence and severity-ranked fixes |

- `mode=local` checks local site files without deploying; `mode=live` fetches the deployed site.
- In `mode=live`, `url` must be the site's bound domain or deployment URL.
- Typical loop:

```text
enhance_seo_audit  site="acme-site"  mode="local"  locale="en"
read_site_file     slug="acme-site"  path="index.html"
write_site_file    slug="acme-site"  path="index.html"  content="…"
write_site_file    slug="acme-site"  path="llms.txt"  content="…"
deploy_site        slug="acme-site"
enhance_seo_audit  site="acme-site"  mode="live"
```

## Connecting external sites

For pages generated by another tool, a script or an existing backend that still need inquiries, chat, subscriptions and tracking:

| Tool | R/W | What it does |
| --- | --- | --- |
| `enhance_api_keys_list` | Read | Inspect `/api/v1` keys: type, prefix, modules, origin allowlist, enabled / revoked state and last use; never returns the secret |
| `enhance_embed_get` | Read | Return the `enhance.js` snippet, inquiry / subscribe form snippets and `/api/v1` details; check which pages already load the script and which forms are bound |
| `enhance_embed_inject` | Write | Inject `enhance.js` into externally generated HTML; all HTML pages by default, idempotently skipping pages that already include it |

- With no usable key, `enhance_api_keys_list` returns a console `createUrl` so the user can create one under **Site enhancements → API access**.
- Injected pages are marked for deployment; verify with `enhance_embed_get`, then call `deploy_site`.
- Site keys and tokens are never returned to MCP; do not write them into source code.

## Example workflows

**Follow up on leads**

```text
enhance_leads_list    site="acme-site"  status="new"  limit=50
enhance_lead_update   lead_id="lead_123"  status="contacted"  note="Emailed"
```

**Read business performance**

```text
enhance_overview            site="acme-site"
enhance_analytics_summary   site="acme-site"  days=7
```

**Handle live chat**

```text
enhance_chat_conversations  site="acme-site"  status="open"
enhance_chat_messages       conversation_id="conv_123"
enhance_chat_reply          conversation_id="conv_123"  message="…"
enhance_chat_close          conversation_id="conv_123"
```

**Export monthly inquiries**

```text
enhance_export_create  site="acme-site"  type="submissions"  format="csv"  from="2026-10-01"  to="2026-10-31"
enhance_exports_list   site="acme-site"
```

## Boundaries

- Read-only tokens can read everything but cannot modify leads, reply to chats, change settings or create exports.
- Settings tools never return Google secrets, Turnstile secrets or site keys.
- Exports return time-limited signed links, not file contents.
- Data scope follows the account and site permissions; team members below the required role cannot view or change the corresponding data.
